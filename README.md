# Ahmed Elabd — Frontend Portfolio

A responsive, light and elegant portfolio website showcasing four public GitHub projects.

## Preview locally
1. Unzip the downloaded project folder.
2. Open `index.html` in your browser.

No build tools are required.

## Publish online with GitHub Pages
1. Open your GitHub account: https://github.com/ahmedr20
2. Create a new public repository named `ahmedr20.github.io` (or another name you prefer).
3. Upload `index.html`, `styles.css`, and `script.js` to the repository root.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
6. Follow the Pages status in Settings. GitHub will show the published address when deployment finishes.

## Before sharing with employers
- Confirm every project description matches the final project.
- Add live-demo URLs to the project cards once you have deployed each project.
- You can update your email in `index.html` if needed.
- The preview panels are illustrative designs created for this portfolio; they are not screenshots of the actual apps.
